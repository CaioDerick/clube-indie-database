# Clube Indie — Database

Projeto de banco de dados desenvolvido para representar um clube de jogos, permitindo o gerenciamento de estúdios, jogos, categorias, jogadores e plataformas. O Objetivo desse projeto é desenvolver uma estrutura de banco de dados relacional capaz de armazenar e organizar informações sobre jogos, seus desenvolvedores, plataformas disponíveis e jogadores.

# Tecnologias utilizadas

- MySQL
- MySQL Workbench
- SQL

# Estrutura do banco

O banco de dados possui as seguintes entidades:

- Estúdio
- Categoria
- Jogos
- Jogadores
- Plataformas
- Jogadores compram jogos
- Plataformas lançam jogos

# Modelagem

O projeto conta com um diagrama entidade-relacionamento (DER), representando as entidades e seus relacionamentos.
